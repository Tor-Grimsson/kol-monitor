# Icon System

Source: `src/components/icons/`
SVGs: `src/components/icons/svg/` (subdirectories by category)
Registry: `src/components/icons/index.js`

## Usage

```jsx
import { Icon } from '../components/icons'
<Icon name="arrow-up" size={16} />
```

Helpers: `hasIcon(name)`, `getCategory(name)`, `ALL_ICONS` (flat array), `ICONS` (by category).
